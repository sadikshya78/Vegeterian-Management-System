# Login and Registration Flutter App

## Project Description

This project is a simple **Login and Registration mobile application** developed using Flutter and Dart. The main purpose of this project is to practice Flutter user interface design, widgets, layouts, text fields, buttons, password visibility, navigation, and basic form handling.

The application contains two main pages: a **Login Page** and a **Registration Page**. Users can enter their login details, create a new account, and navigate between the two pages.

## Features

* Login Page
* Registration Page
* Application name/logo
* Email / Username input field
* Full Name input field
* Password input field
* Confirm Password input field
* Show/Hide password functionality
* Login button
* Create Account button
* Forgot Password option
* Navigation from Login to Registration
* Navigation from Registration back to Login
* Simple and user-friendly interface

## How to Run the Project

### 1. Install Flutter

Make sure Flutter SDK is installed and properly configured on your computer.

Check the installation by running:

```bash
flutter doctor
```

### 2. Clone the Repository

Clone this GitHub repository using:

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 3. Open the Project

Open the project in **Android Studio** or **Visual Studio Code**.

### 4. Install Dependencies

Run the following command in the project terminal:

```bash
flutter pub get
```

### 5. Run the Application

Connect an Android device or start an Android emulator and run:

```bash
flutter run
```
